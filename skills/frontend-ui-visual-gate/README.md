# Frontend UI Visual Gate

一个在前端 UI 架构与编码开始前强制完成视觉方向对齐的 Codex Skill。

> 迁移说明：根据仓库根目录的 [`MIGRATION.md`](../../MIGRATION.md)，本 Skill 的来源是本机已安装并完成前测的 `frontend-ui-visual-gate` 包，迁移前没有独立 GitHub 仓库，也没有可直接恢复的原仓库 README。本说明依据迁移时保留的 [`SKILL.md`](./SKILL.md) 整理。

## 解决的问题

前端任务常因“改动很小”“已有截图”或“先搭骨架”而跳过视觉确认，最终实现虽然可运行，却不符合用户对品牌、情绪、信息密度或交互体验的预期。

本 Skill 设置两个明确门禁：

1. 开发前询问用户是否先生成 2–4 种效果图，并确认期望的心理感受。
2. 用户同意生图后，必须明确选择一个方向或组合方案，才能进入架构与编码。

如果用户明确拒绝生图，Skill 会记录跳过原因和视觉约束，再按文字需求、现有设计系统或已批准 mockup 继续。

## 适用范围

以下任务会触发视觉门禁：

- 新建或调整页面、组件、布局、导航、表单、卡片与按钮；
- 修改主题、颜色、字体、间距、圆角、阴影、动效或响应式行为；
- 处理 hover、focus、disabled、loading、error 等交互状态；
- 调整 UI 文案或“更现代、更高级、更可信、更轻松”等用户感受。

## 工作流

```text
识别 UI 任务
  -> 门禁 A：询问是否生成效果图并确认心理预期
      -> 用户拒绝：记录跳过决定与约束 -> 进入开发
      -> 用户同意：生成 2–4 个差异明确的方向
          -> 门禁 B：用户明确选择单一或组合方向
              -> 固化视觉决策简报 -> 架构 -> 开发 -> 回归验证
```

视觉决策简报会记录：视觉方向、目标心理感受、必须保留的元素、颜色与字体等约束、响应式意图、无障碍底线、明确避开的风格，以及用户的选择依据。

## 安装

将本目录复制到 Codex 的 skills 目录：

```bash
cp -R skills/frontend-ui-visual-gate ~/.codex/skills/
```

Codex 也支持将其安装到跨运行时目录 `~/.agents/skills/`。

## 使用

安装后，创建或修改前端界面时会自动触发。也可以明确要求：

```text
使用 frontend-ui-visual-gate，先对齐视觉方向，再实现这个页面。
```

完整的触发条件、状态机、视觉方案要求、交接模板与失败纠偏规则请参阅 [`SKILL.md`](./SKILL.md)。
